Every call here maps to one real request against your API. Nothing is simulated once it leaves this panel — the ledger on the right is what actually came back.

1Request

Ask for a resource. With no payment attached, the API answers 402 and hands you a challenge: who to pay, how much, and a nonce.

GET /resource/<id>
2Redeem

Pay the challenge on Algorand TestNet, then hand back the payment's transaction id. The API verifies it, hashes the response, and stamps that hash into a new on-chain note.

GET /resource/<id> · X-PAYMENT header
3Verify

Re-fetch the audit note straight from the chain and re-derive it independently — proving the local cache hasn't drifted from what's actually recorded.

GET /verify/<payment_txn_id>
Needs a live instance of this API reachable from your browser (uvicorn app.main:app --reload). CORS is already open in app/main.py for local use. This console makes no network calls anywhere except the API base URL above.
